## Pipeline de integración continua
GitHub (`main`) → **AWS CodePipeline** (`blacklist-ci-pipeline`) → **AWS CodeBuild** (`blacklist-ci`) → artefacto en **Amazon S3**. Sin etapa de Deploy (la entrega es solo CI).

- Cada commit o merge a `main` dispara el pipeline automáticamente (webhook de la conexión AWS–GitHub).
- `buildspec.yml`: instala dependencias (Python 3.12), ejecuta las pruebas unitarias con reporte JUnit y de cobertura y, **solo si pasan**, genera el artefacto desplegable.
- Si una prueba falla, el build falla y **no se genera artefacto**.

## Pruebas unitarias
- **31 pruebas** con pytest, al menos un escenario por endpoint: `GET /health`, `POST /blacklists` y `GET /blacklists/<email>`.
- Sin motor de base de datos externo (SQLite en memoria).
- Cobertura en AWS CodeBuild: **95,62 % de líneas** y **100 % de ramas**.
